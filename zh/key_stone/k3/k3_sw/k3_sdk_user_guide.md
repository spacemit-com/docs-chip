# K3 SDK 概览

K3 芯片提供多套软件开发套件（SDK），覆盖嵌入式 Linux、通用操作系统、物联网平台及机器人应用等多种场景。各 SDK 均提供完整的软件栈支持，包括 BSP、工具链、示例工程及开发文档，开发者可根据产品定位灵活选择。

## Buildroot SDK  

Buildroot SDK 为 K3 芯片提供轻量级 Linux BSP 方案，包括 OpenSBI、U-Boot/UEFI、Linux 内核以及可裁剪的根文件系统（含中间件与示例）。面向需要快速构建定制化嵌入式系统的开发场景，支持驱动与应用扩展。

- **使用说明：** [K3 Buildroot 使用指南](https://www.spacemit.com/community/document/info?lang=zh&nodepath=software/SDK/buildroot/k3_buildroot/intro.md)

## Bianbu SDK  

Bianbu 是针对 RISC-V 架构深度优化的操作系统，基于 Ubuntu 社区源码构建，具备良好兼容性与可扩展性，适用于通用计算、智能终端及行业场景的产品化开发。

- **使用说明：** [Bianbu SDK 使用指南](https://www.spacemit.com/community/document/info?lang=zh&nodepath=software/SDK/bianbu/root_overview.md)

## K3 OpenHarmony SDK（K3 OH6.x）  

K3 OpenHarmony SDK 基于 OpenHarmony 6.x 版本，由中科院软件所联合进迭时空完成适配，面向分布式物联网操作系统场景。

- **使用说明：** [OpenHarmony 使用指南](https://www.spacemit.com/community/document/info?lang=zh&nodepath=software/SDK/openharmony/root_overview.md)

## AI Robot SDK  

AI Robot SDK 是面向机器人规模化落地的一体化全栈软件开发套件，提供从系统到中间件与应用的标准化能力与工程化工具链，显著降低集成复杂度并加速交付。内置丰富组件库与场景化示例工程，覆盖桌面机器人、人型机器人、无人机、机械臂等多形态平台，帮助开发者快速验证、快速集成、快速量产部署。

- **使用说明：** [K3 AI Robot SDK 使用指南](https://www.spacemit.com/community/document/info?lang=zh&nodepath=software/SDK/ros/k3)
