# K3 Hardware AVL

The **AVL** contains validated and production-proven components compatible with the K3 platform, including:

- LPDDR5  
- UFS  
- eMMC

The AVL ensures device compatibility, assists with component selection, and supports supply chain planning. This list is updated periodically.
