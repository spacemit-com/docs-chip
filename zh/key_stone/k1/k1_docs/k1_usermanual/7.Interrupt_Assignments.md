# 7. 中断分配

## 7.1 简介

K1 包含以下中断控制模块：

* 一个处理器核本地中断控制器（**CLINT**）
* 一个平台级中断控制器（**PLIC**）

**CLINT** 是嵌入在 **SpacemiT® X60™ RISC-V 主 CPU** 中的单一功能模块。它负责汇集所有主 CPU 的中断源，并将中断分发到 **各个主 CPU hart**。

**PLIC** 则是嵌入在 **Sensor-Hub 子系统** 中的单一功能模块。它负责汇集所有 Sensor-Hub 子系统的中断源，并将中断分发到 **RISC-V 实时 CPU**。
