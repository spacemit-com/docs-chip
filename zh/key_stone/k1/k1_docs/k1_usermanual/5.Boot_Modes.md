# 5. 启动模式（Boot Modes）

## 5.1 概述

K1 支持从以下存储介质启动：

- SPI NAND Flash
- SPI NOR Flash
- eMMC
- SD/TF 卡

## 5.2 启动绑带引脚（Boot Strapping Pins）

K1 的启动流程由一组启动绑带引脚控制。通过不同的引脚配置，可以选择启动模式以及其他运行参数。启动绑带引脚的定义如下表所示。

| 引脚名称      | 启动绑带引脚   | 默认值 |
| --------- | -------- | --- |
| QSPI_DAT0 | STRAP[0] | 0   |
| QSPI_DAT1 | STRAP[1] | 0   |
| QSPI_DAT2 | STRAP[2] | 0   |
| QSPI_DAT3 | STRAP[3] | 0   |
| GPIO90    | STRAP[4] | 0   |

不同启动绑带引脚组合的具体功能说明见以下各小节。

### 启动模式选择（Boot Mode Selection）

启动模式由 **STRAP[0]** 和 **STRAP[1]** 引脚的状态决定，如下表所示。

| 序号 | STRAP[1] | STRAP[0] | 启动模式                     |
| -- | -------- | -------- | ------------------------ |
| 1  | Down     | Down     | SD/TF 卡 → eMMC（默认）       |
| 2  | Up       | Down     | SD/TF 卡 → SPI NAND Flash |
| 3  | Down     | Up       | SD/TF 卡 → SPI NOR Flash  |
| 4  | Up       | Up       | SD/TF 卡                  |

### 下载模式选择（Download Mode Selection）

下载模式由 **STRAP[2]** 引脚的状态决定，如下表所示。

| 序号 | STRAP[2] | 下载模式    |
| -- | -------- | ------- |
| 1  | Down     | USB（默认） |
| 2  | Up       | UART    |

### 启动 / 下载模式选择（Boot Download Mode Selection）

启动或下载模式由 **STRAP[3]** 引脚的状态决定，如下表所示。

| 序号 | STRAP[3] | 启动 / 下载模式说明                                           |
| -- | -------- | ----------------------------------------------------- |
| 1  | Down     | 按 **[启动模式选择](#启动模式选择boot-mode-selection)** 执行启动（默认）   |
| 2  | Up       | 按 **[下载模式选择](#下载模式选择download-mode-selection)** 进入下载模式 |

### SPI NAND / NOR Flash 启动电压选择

SPI NAND / SPI NOR Flash 的启动 I/O 电压由 **STRAP[4]** 引脚的状态决定，如下表所示。

| 序号 | STRAP[4] | SPI NAND / NOR Flash 启动电压 |
| -- | -------- | ------------------------- |
| 1  | Up       | 3.3V I/O                  |
| 2  | Down     | 1.8V I/O                  |
