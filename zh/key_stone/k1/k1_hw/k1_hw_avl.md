# K1 硬件物料清单（BOM / AVL）

**AVL（Approved Vendor List）** 包含经验证、可量产的 K1 平台兼容器件，包括但不限于：

- DDR  
- eMMC / UFS  
- Wi-Fi / Bluetooth 模组  
- SPI NOR / SPI NAND  
- LCD / 触摸屏  
- 摄像头模组  
- 传感器 / GPS  
- 其他可选外设

AVL 用于确保器件兼容性，辅助元器件选型，并支持供应链规划。
