# 7. Interrupt Assignments

K3 contains an Advanced Core Local Interruptor (ACLINT) and an Advanced Platform Level Interrupt Controller (APLIC).

- ACLINT, as the local interrupt controller, includes the following functions:
  - Hart local software interrupt control
  - Hart local timer interrupt control

- APLIC, as the external interrupt controller, includes the following functions:
  - Support for up to 1023 external interrupts
  - MSI output mode only
  - Hardware-configurable interrupt delegation
  - Support for interrupt modes 0, 1, and 4-76 for non-delegated interrupts
  - Support for hartid up to 16383
  - Configurable EIID width
