# K3 Hardware Resources

This section summarizes the hardware resource files for the K3 chip.

## Pin Control

### Pin List and Pinmux

This file contains the complete pin list and pin multiplexing configuration details.  
[k3_pinlist_pinmux_v21.xlsx](https://cdn-resource.spacemit.com/file/chip/K3/k3_pinlist_pinmux_v21.xlsx)

### Pin Map

This file describes the mapping between the package pins and the on-chip modules and interfaces.  
[k3_PINMAP_V1.1.xlsx](https://cdn-resource.spacemit.com/file/chip/K3/k3_PINMAP_V1.1.xlsx)

## Timing Configuration

### Pin Delay

This file defines the input and output timing delay configuration for high-speed interfaces.  
[k3_pin_delay_V1.0.xlsx](https://cdn-resource.spacemit.com/file/chip/K3/k3_pin_delay_V1.0.xlsx)

## Package Information

### POD (Package Outline Drawing)

This file includes package dimensions, the BGA ball layout, ball pitch, and other mechanical specifications.  
[k3_pod.pdf](https://cdn-resource.spacemit.com/file/chip/K3/k3_pod.pdf)
