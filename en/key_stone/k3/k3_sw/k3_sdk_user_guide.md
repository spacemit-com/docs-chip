# K3 SDK Overview

The K3 platform provides multiple Software Development Kits (SDKs) to support a wide range of application domains, including embedded Linux systems, general-purpose operating systems, IoT platforms, and robotics.

Each SDK delivers a complete software stack, including Board Support Package (BSP), toolchains, reference examples, and development documentation. Developers can select the most suitable SDK based on their product requirements and deployment scenarios.

## K3 Buildroot SDK  

The Buildroot SDK provides a lightweight Linux BSP solution for the K3 platform. It includes OpenSBI, U-Boot / UEFI, the Linux kernel, and a highly customizable root filesystem with integrated middleware and example applications.

This SDK is designed for embedded use cases that require fast system bring-up and high flexibility, with full support for driver development and application extension.

- **User Guide:**  
  [K3 Buildroot User Guide](https://www.spacemit.com/community/document/info?lang=en&nodepath=software/SDK/buildroot/k3_buildroot/intro.md)

## Bianbu SDK  

Bianbu is a RISC-V optimized operating system distribution built on the Ubuntu ecosystem. It provides strong compatibility, rich software support, and excellent scalability.

This SDK is suitable for product development in general-purpose computing, intelligent devices, and industry-specific applications that require a full-featured Linux user-space environment.

- **User Guide:**  
  [Bianbu SDK User Guide](https://www.spacemit.com/community/document/info?lang=en&nodepath=software/SDK/bianbu/root_overview.md)

## K3 OpenHarmony SDK (K3 OH 6.x)  

The K3 OpenHarmony SDK is based on OpenHarmony version 6.x, jointly adapted by the Institute of Software, Chinese Academy of Sciences, and SpacemiT for the K3 platform.

It is designed for distributed IoT operating system scenarios, enabling lightweight system deployment and cross-device collaboration.

- **User Guide:**  
  [OpenHarmony User Guide](https://www.spacemit.com/community/document/info?lang=zh&nodepath=software/SDK/openharmony/root_overview.md)

> Note: Only Chinese version available 

## AI Robot SDK  

The AI Robot SDK is a full-stack, production-oriented software development kit designed for scalable robotics deployment. It provides standardized capabilities from the operating system layer to middleware and application frameworks, along with an engineering toolchain to streamline development.

The SDK includes a rich set of components and scenario-based reference projects, covering platforms such as service robots, humanoid robots, drones, and robotic arms. It enables rapid prototyping, integration, and mass production.
